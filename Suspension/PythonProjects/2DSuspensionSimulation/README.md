# INTRODUCTION
A simple 2D suspension kinematic simulation in Python that utilizes pygeosolve which use scipy to solve kinematic constraints
This simulation currently only calculate camber angle and roll center
This project REQUIRES a modified pygeosolve library which use faster solvers and added utility methods

# REQUIREMENTS
- Python
- Modified pygeosolve: https://github.com/SeanPhamISU/pygeosolve
- Matplotlib
- Scipy
- Sympy
